# 🌐 Portfolio Website – Gourangi Sharma

## 📌 Overview

This is my personal portfolio website designed to showcase my skills, projects, achievements, and professional journey in the field of Artificial Intelligence and Data Science. The website provides visitors with an overview of my technical expertise, academic background, and project portfolio.

* Responsive and modern user interface
* About Me section

* Projects section with descriptions

* Contact Information

* Smooth navigation and interactive design

## 💻 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Gourangisharma/Portfolio--gourangi.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio--gourangi
   ```

3. Open `index.html` in your browser.
